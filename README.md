## 📌 Overview
This repository contains my solutions for the **Week 7 Assignment** in the PLP Academy [Database Systems](https://academy.powerlearnprojectafrica.org/module/6a259fb4911523cdf74594d3?study=false) module. The project demonstrates practical mastery of database normalization techniques—transforming unnormalized tables into First Normal Form (1NF) and Second Normal Form (2NF) by eliminating repeating groups and partial dependencies.

---

## 🎯 Learning Objectives
- Understand the principles of good database design and relational data integrity.
- Apply normalization techniques to eliminate data redundancy and anomalies.
- Transform unnormalized multi-valued cells into **First Normal Form (1NF)**.
- Remove partial dependencies to achieve **Second Normal Form (2NF)**.
- Define proper primary keys and foreign keys for relational table structures.
